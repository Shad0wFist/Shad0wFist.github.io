Главная/API

Scene API

Работа со сценами и префабами: screw.scene.*.

Функции

ФункцияСигнатураОписание
load(path, opts) → SceneЗагружает сцену синхронно
load_async(path, cb)Фоновая загрузка с колбэком
unload(scene)Выгружает сцену и её сущности
current() → SceneАктивная сцена
stream(path, radius)Потоковая подгрузка вокруг точки

Пример: смена уровня

scene_example.lualua
screw.scene.load_async("scenes/level_02.scw", function(sc)
    screw.scene.unload(screw.scene.current())
    sc:set_active()
    screw.log.info("уровень 2 готов, сущностей:", sc:entity_count())
end)

Префабы

prefab_example.lualua
local p = screw.prefab.load("prefabs/enemy.scw")
local e = p:instantiate()
e:set_position(vec3(3, 0, 3))
e:set_parent(screw.scene.current():root())
Память

Выгруженная сцена освобождает и ассеты, если на них нет ссылок из других сцен: счётчик ссылок ведёт Crate.
