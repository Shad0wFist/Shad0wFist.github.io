Обзор API

API доступен из Lua и JS под одним именем — screw.

Пространства имён

МодульНазначениеСтраница
screw.coreСущности, компоненты, системы, время, логCore API
screw.sceneСцены, префабы, загрузка/выгрузкаScene API
screw.physicsRaycast, запросы тел, событияРуководство
screw.renderСвет, камеры, пост-эффектыРуководства
screw.inputОсь, кнопки, геймпадCore API

Соглашения

  • Все координаты — метры, углы — радианы, время — секунды;
  • Идентификатор сущности (EntityId) — целое, 0 означает «нет»;
  • Функции, меняющие мир, безопасны только внутри систем;
  • Суффикс _async означает отложенное выполнение до конца кадра.
Стабильность

API помечен как стабильный с 2.0. Ломающие изменения выходят только в мажорных версиях и описаны в changelog.
