Конфигурация

Весь проект описывается одним файлом screwdriver.toml в корне.

Полный пример

screwdriver.tomltoml
[project]
name        ="my_first_game"
version     ="0.1.0"
engine      ="2.4"
entry_scene ="scenes/main.scw"

[render]
backend     ="vulkan"        # vulkan | opengl | webgpu
vsync       =true
target_fps  =144
msaa        =4

[render.clustered]
enabled     =true
max_lights  =2048
cell_size   =32

[physics]
step_hz     =120             # фиксированный шаг Bolt
gravity     =[0.0, -9.81, 0.0]
sleeping    =true

[audio]
master_volume =0.8
channels      =32

[build]
platforms   =["windows", "web"]
compress    ="brotli"
minify_js   =true

Таблица ключей

КлючТипПо умолчаниюОписание
render.backendstringvulkanГрафический бэкенд
render.target_fpsint60Целевая частота кадров
render.msaaint4Сглаживание: 0, 2, 4, 8
physics.step_hzint120Частота шагов физики
physics.gravityvec3[0,-9.81,0]Вектор гравитации
build.compressstringnonenone | gzip | brotli

Переопределение из окружения

Любой ключ можно переопределить переменной вида SCREW_<SECTION>_<KEY>:

терминалbash
SCREW_RENDER_TARGET_FPS=60 screw run
SCREW_PHYSICS_STEP_HZ=60 screw run   # медленная физика для отладки
Проверка конфигурации

Команда screw config check валидирует файл и подсвечивает неизвестные ключи до запуска игры.
