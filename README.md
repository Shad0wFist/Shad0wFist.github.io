# Screwdriver Engine — документация (статический сайт)

Это корень сайта документации игрового движка **Screwdriver 2.4**.
Сайт полностью статический: HTML + CSS + ванильный JS, без сборки и без внешних CDN.

## Структура

    index.html                 главная
    about/  blog/              о движке, блог
    getting-started/           установка, конфигурация, первые шаги
    guides/                    руководства (ECS, физика, скриптинг, troubleshooting)
    api/                       справочник API
    examples/                  готовые примеры игр
    changelog.html  faq.html   история изменений и FAQ
    admin/  login/             служебные страницы (мишени для правил WAF / rate limit)
    assets/css|js|images|videos ресурсы
    search-index.json          индекс для клиентского поиска
    style.css                  основная тема (тёмная по умолчанию + светлая)
    assets/js/theme.js         переключатель тем (выбор хранится в localStorage)
    .nojekyll                  отключает обработку Jekyll на GitHub Pages

## Локальный запуск

    python3 -m http.server 8000
    # затем открыть http://localhost:8000

Поиск (`search-index.json`) требует HTTP-сервер; при открытии файлов двойным
кликом он вежливо сообщит, что индекс недоступен, остальной сайт работает.

## Пересборка

Страницы генерируются скриптом из каталога `tools/` (не входит в сайт):

    python3 tools/build_all.py

## Публикация на GitHub Pages

Содержимое этого каталога = корень репозитория `<логин>.github.io`.
После подключения собственного домена добавьте в корень файл `CNAME`
с именем домена (одной строкой, без пробелов).
