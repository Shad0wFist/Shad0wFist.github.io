Сцены и сущности (ECS)

В Screwdriver нет «объектов со всем сразу». Есть три понятия: сущность, компонент и система.

Три кита

ПонятиеЧто этоПример
EntityЦелочисленный идентификатор, сам по себе пуст42
ComponentЧистые данные без методовTransform, RigidBody
SystemФункция, обходящая сущности с нужным набором компонентовPhysicsSystem

Создание сущности

scripts/spawn.lualua
local id = screw.spawn("Crate_01")

screw.add(id, "Transform", { position = vec3(2, 0.5, -3), rotation = 0 })
screw.add(id, "MeshRenderer", { mesh = "meshes/crate.scw", cast_shadows = true })
screw.add(id, "RigidBody",    { mass = 12.0, friction = 0.6 })
screw.tag(id, "destructible")

Запросы (archetypes)

Система объявляет, какие компоненты ей нужны, — ядро само держит плотные массивы только подходящих сущностей, поэтому обход быстр и предсказуем.

scripts/gravity.lualua
local Gravity = screw.system("Gravity")
Gravity.requires = { "Transform", "RigidBody" }   -- запрос

function Gravity:update(dt)
    for id, tr, rb in Gravity:each() do           -- плотный обход без аллокаций
        rb.velocity.y = rb.velocity.y - 9.81 * dt
        tr.position   = tr.position + rb.velocity * dt
    end
end
Почему это быстро

Компоненты одного архетипа лежат в памяти подряд — CPU грузит их кэш-линиями, а не прыгает по указателям. На 10 000 сущностей обход занимает доли миллисекунды.

Сцены и префабы

Сцена (.scw) — сериализованный набор сущностей. Префаб — та же сцена, но пригодная для вставки copies во время игры:

scripts/prefab.lualua
local crate = screw.prefab.load("prefabs/crate.scw")
for i = 1, 20 do
    local e = crate:instantiate()
    e:set_position(vec3(i * 1.2, 4 + i, 0))
end

Диаграмма кадрового цикла, где системы вызываются по порядку, — на странице «О движке».
