Скриптинг Torque

Игровая логика пишется на Lua 5.4 или JavaScript. Оба языка видят одно и то же API.

Жизненный цикл системы

scripts/lifecycle.lualua
local S = screw.system("Example")

function S:on_start()   end   -- один раз при старте сцены
function S:update(dt)   end   -- каждый кадр (после физики)
function S:fixed_update(dt) end -- каждый шаг физики (120 Гц)
function S:on_render()  end   -- перед отправкой кадра (камеры, эффекты)
function S:on_stop()    end   -- при выгрузке сцены

То же самое на JavaScript

scripts/lifecycle.jsjs
import { system, each, input } from "screwdriver";

export default system("Example", {
  update(dt) {
    for (const [id, body] of each("RigidBody")) {
      body.velocity.x = input.axis("horizontal") * 6.0;
    }
  },
});

Горячая перезагрузка

Редактор следит за каталогом scripts/. Сохранение файла подменяет код «на лету», состояние систем сохраняется через S.state.

scripts/counter.lualua
local S = screw.system("Counter")
S.state = S.state or { ticks = 0 }   -- переживёт hot reload

function S:update(dt)
    S.state.ticks = S.state.ticks + 1
end
Профилируйте, а не гадайте

Команда screw profile --frames 600 снимет flame chart и покажет, какая система самая дорогая. Пример отчёта — на скриншоте в блоге.
